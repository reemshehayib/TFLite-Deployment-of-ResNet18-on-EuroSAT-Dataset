# EuroSAT Classification (ResNet18 → TFLite)

This project trains a ResNet18 model on the EuroSAT dataset and converts it to TensorFlow Lite for efficient inference.

## Main Functionalities:
--> Trains a ResNet18 model (PyTorch)  
--> Evaluates accuracy and performance of the main model  
--> Converts the model to TFLite (FP32 and INT8)  
--> Benchmarks inference speed  
--> Visualizes results (confusion matrix, reports)
